# Air Pollution Analysis and Prediction

## Project Overview
This project focuses on analyzing air pollution data and applying machine learning techniques to understand pollution patterns and predict pollution levels.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Apply regression models for prediction.
- Implement classification models to classify pollution levels into Lower and Elevated categories.
- Evaluate machine learning model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Techniques
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree
- Support Vector Machine (SVM)

## Project Files
- `Project.py` – Python implementation of data analysis and machine learning models.
- `Dataset.csv` – Dataset used for analysis (if included).

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Run `Project.py`.
